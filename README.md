EXP 17 : Basic Charts and Visual Encoding

Theory

Line Chart

A line chart is used to represent data trends over time or across ordered categories. It connects data points using straight lines, making it easy to observe patterns such as increase or decrease. Line charts are widely used for analyzing continuous data like study hours, temperature, or sales trends.

Bar Chart

A bar chart is used to compare values across different categories. It represents data using rectangular bars, where the height or length of each bar corresponds to the value it represents. Bar charts are useful for comparing discrete data such as marks obtained on different days.

Matplotlib Library

Matplotlib is a popular Python library used for data visualization. It provides functions to create various types of graphs such as line charts, bar charts, histograms, and scatter plots. It allows customization of charts using titles, labels, colors, and markers.

Seaborn Library

Seaborn is a data visualization library built on top of Matplotlib. It provides a higher-level interface for creating attractive and informative statistical graphics. Although not heavily used in this experiment, it enhances the visual appearance of plots.

Visual Encoding

Visual encoding refers to the use of graphical elements such as color, size, shape, and position to represent data. In charts, visual encoding improves clarity and helps users quickly understand the information being presented.

Markers and Labels

Markers are symbols used to highlight data points in a graph, such as circles or squares. Labels such as axis labels and titles help describe the data being visualized, making the graph easier to interpret.

Legends

Legends are used to differentiate multiple data series in a single graph. They help identify which line or bar corresponds to which dataset, especially in comparative charts.

DataFrame Usage

A DataFrame is used to organize data in rows and columns. It allows easy access and manipulation of data, which can then be visualized using plotting libraries like Matplotlib.

Conclusion

Thus, basic charts and visual encoding techniques were studied and implemented successfully. Line charts and bar charts were created to visualize data trends and comparisons. Various elements such as markers, labels, legends, and colors were used to enhance the clarity of the graphs. The experiment demonstrated how data visualization helps in better understanding and analysis of data.
